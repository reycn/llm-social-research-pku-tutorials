# Replication of Card (1993): College Proximity and the Return to Schooling

A minimal, fully reproducible research project that estimates the effect of
education on income using the identification strategy in Card, D. (1993),
*Using Geographic Variation in College Proximity to Estimate the Return to
Schooling* (NBER Working Paper No. 4483).

One R script performs every step: it installs/loads the required packages,
exports the raw and cleaned data, estimates three models, draws both figures,
and exports the APA-7 table and the results paragraph. All numbers in the
deliverables are generated by R from the fitted models.

## Research question

What is the effect of additional years of schooling on hourly wages, and how
does an instrumental-variables estimate that uses college proximity compare
with conventional ordinary least squares?

## Quick start

```bash
# from the project root
Rscript script/01_card1993_replication.R   # data, models, figures, tables, paragraph
./sync_results.sh                          # copy figures/tables into paper/
cd paper && latexmk -pdf main.tex          # build the APA-7 manuscript
```

The R script is idempotent and installs any missing CRAN package automatically.
It was developed with R 4.6.0; `sessionInfo()` is saved to
`data/result/session_info.txt`.

## Data

The analysis uses the 3,010 men in the National Longitudinal Survey Young Men
cohort with valid 1976 wage and schooling data. The extract is distributed as
the `card` data set in the **wooldridge** R package; the script writes it to
`data/raw/card1993_nls_raw.csv` and then writes the cleaned analysis file to
`data/cleaned/card1993_analysis.csv`. No observations are dropped: all model
variables are complete for the 3,010 men.

| Variable | Description |
|---|---|
| `lwage` | log hourly wage (1976 cents) |
| `educ` | years of schooling |
| `nearc4` | grew up in a labor market with a four-year college (1966) |
| `black`, `south`, `smsa`, `smsa66` | demographic and location indicators |
| `reg662`–`reg669` | census-region indicators (Northeast / `reg661` is the reference) |
| `exper`, `expersq` | potential experience and its square |

## Models

1. **Model 1** — OLS: `lwage ~ educ`.
2. **Model 2** — OLS with controls: `lwage ~ educ + black + south + smsa +
   smsa66 + reg662 + ... + reg669 + exper + expersq`.
3. **Model 3** — 2SLS: `educ` instrumented by `nearc4`, with the same controls.
   Classical (homoskedastic) standard errors are used, matching Card's reported
   precision.

## Key results

| Model | Return to one year of schooling (log points) | 95% CI | Implied wage change |
|---|---|---|---|
| Model 1: OLS, no controls | 0.052 | [0.046, 0.058] | +5.3% |
| Model 2: OLS, with controls | 0.075 | [0.068, 0.082] | +7.8% |
| Model 3: 2SLS, `nearc4` | 0.132 | [0.024, 0.239] | +14.1% |

The first-stage F statistic on the excluded instrument is 13.26
(df = 1, 2994; p < .001). The 2SLS estimate matches Card's preferred
structural estimate (0.132, SE = 0.055) to three decimal places. The full
comparison is in `data/result/replication_comparison.csv`, and the complete
coefficient table is in `output/tex/table1.md` (Markdown) and
`output/tex/table1.tex` (LaTeX).

## Reproducibility notes

- Figures follow `docs/APA/FIGURE.md`: `ggplot2` with `theme_bw()`, no titles or
  subtitles, colour-blind-safe palette (`#0072B2`, `#D55E00`, `#009E73`),
  minimal gridlines, a grey dashed zero line in the effect-size plot, vector
  PDF plus 320-dpi PNG, and fixed scales when comparing effects.
- The table follows `docs/APA/TABLE.md`: APA-7 layout with top/bottom/header
  rules only, three-decimal estimates without leading zeros, 95% CIs, N, R²,
  adjusted R², region controls, and the first-stage F for 2SLS.
- The paragraph follows `docs/APA/STATISTICS.md` and `docs/APA/LATEX-APA.md`:
  italic statistical symbols, `p` values without a leading zero, CIs in
  brackets, and a topic sentence, evidence, magnitude, and interpretation.
- The manuscript uses the `apa7` class with `biber`/`biblatex` and
  `\textcite{}`/`\parencite{}` citations.
